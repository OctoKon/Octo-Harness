# Workbench fonts

The approved PR #4 typography uses Geist Variable and Crimson Text, both pinned to Fontsource 5.3.0 from the existing prototype lockfile. Both use OFL-1.1; complete licenses are retained alongside this file. The packages contain only CSS/font assets and add no runtime JavaScript or transitive dependencies. Vite bundles these assets locally; the app does not fetch web fonts. Validate the selected fonts in the production bundle and packaged light/dark screens.
