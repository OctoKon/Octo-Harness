# Document and multimodal tools

**Active product scope:** Splyce keeps agent execution and stored state local. Each inference role may use a local runtime or an explicitly authorized cloud API profile with recorded endpoint, model/revision, and egress scope; it never silently switches provider or falls back. Hosted memory and executors below remain comparative research, not product dependencies. [Current master plan](../../../MASTER-PLAN.md).

Snapshot: **2026-10-25**. Public-source findings and proposed tool contracts; extraction, rendering, retrieval and model-quality measurements are **n=0**. No candidate is bundled by default. Record the exact code/package/model revision, integrity, license and dependency assets before adoption. Source-code license and model/data/font licenses are separate. A Rust implementation is useful only if its total integration and supported-output behavior beats the simpler qualified alternative.

## Proposed artifact contract

An imported artifact keeps original bytes/digest, scoped source ID, media type, declared size, producer and retention class. A derived projection adds converter/model revision, options, page/region/time/cell provenance and explicit omissions. Preserve formulas, spreadsheet values and rendered text as distinct evidence; Markdown cannot promise to round-trip Office layout, formulas or embedded objects. Unsupported/encrypted/truncated content yields an explicit partial or unavailable result, never an empty successful document.

Extraction does not execute embedded instructions, macros or linked programs. Decode/render/OCR runs in an owned worker with scoped filesystem and network grants. Linked assets and remote transcription/VLM requests require their own egress decision. Document text cannot approve a command or expand scope. Enforce declared memory/time/decoded-size limits at the worker boundary and report refusal or partial coverage; no hidden truncation marketed as complete parsing.

For multimodal model calls, capability metadata distinguishes image, PDF, audio, video and structured tool input/output. Record page/image transformations, downsampling, frame/time selection, known omissions, and the selected local or explicitly authorized cloud inference profile. The local-only profile denies hosted dispatch for OCR, transcription, visual embedding, extraction, reranking, and generation. Missing usage for images/audio remains unavailable or separately estimated with a stated method.

## Negative and quality gates

| Case                          | Required observation                                                                                                                                                                                                        |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Extraction fidelity           | Synthetic multi-column PDF, table, formula, scan, non-Latin text and spreadsheet fixture produce cited spans/cells/pages or explicit missing coverage. No text-only score certifies layout fidelity.                        |
| Untrusted input and resources | Embedded instructions remain data; external resource fetch is denied without a grant. Worker cancellation, malformed input and oversized decoded content leave no unmanaged process or scratch artifact.                    |
| Rust/native comparison        | Same corpus and frozen assets across candidate versions; compare supported semantics and declared exact outputs, total latency/peak memory/disk and installation burden. No inherited publisher speed claim.                |
| Multimodal retrieval          | Independently labeled text-heavy, table/chart, image-only and mixed pages; equal evidence/quality criteria against lexical, OCR/hybrid and visual arms. Include lost-source and stale-render cases.                         |
| Generated deliverable         | Editable source, successful actual compiler, correct numbers/formulas, rendered page/slide inspection and final output identity. File existence alone fails the gate.                                                       |
| Retention and egress          | Scope withdrawal blocks new processing; delete raw, OCR, transcript, thumbnails, page images, vectors, previews and caches; restored backup cannot reopen deleted evidence. Local-only fixture observes no hosted dispatch. |
