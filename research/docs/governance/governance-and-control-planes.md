## Proposed composition

The host remains the sole run, permission and memory owner. An optional fleet service submits scoped tasks; a credential service grants narrow credentials; a gateway handles only declared routes; an executor advertises its actual boundary. Each returns a receipt to the same journal. None can make a plugin more privileged than its parent run or turn a retrospective check into prevention.

Before adoption, pin a version and license, exercise a real permitted operation and a denied operation, interrupt it during execution, reconcile the observed effect, then prove teardown and evidence export.
