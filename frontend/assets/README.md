# Original interface artwork

`harness-flow.svg` is original Splyce vector artwork. It illustrates the proposed task → Pi → policy → tools → evidence → memory relationship in the [master plan](../../MASTER-PLAN.md), rather than a connected runtime.

The artwork follows the repository's [AGPL-3.0-only license](../../LICENSE). It uses no stock imagery, remote image host or external font. Accessible text describes the image, and a focusable horizontal viewport preserves diagram legibility on narrow screens. Neutral strokes and copper paths reuse the existing palette.
