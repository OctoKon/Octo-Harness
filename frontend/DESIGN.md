# Splyce frontend design

## Overview

A task-first workspace with four main destinations: Build, Runs, Memory and Models. Advanced settings remain available through a collapsed Workspace controls group. Source-linked research stays separate from simulated execution.

## Colors

Ink and lilac establish the interface; coral identifies primary actions. Status colors always include text. Light, Dark and System modes apply to the complete page. System follows the device setting and updates when it changes.

## Typography

Manrope is bundled under its retained open font license. Consolas is used only for code and identifiers. Main actions and task names take precedence over metadata.

## Layout

The desktop sidebar is 216px and narrows to 185px at 880px. Below 640px it becomes a drawer with a backdrop, Escape handling and contained keyboard navigation. The product page stacks its explanation and interactive sample on phones. The task composer remains the main workspace action.

## Elevation & Depth

Fine borders and tonal fields separate most content. The interactive specimen and notifications use soft neutral shadows. Reduced-motion preferences disable the specimen's hover movement.

## Shapes

The rounded S monogram uses a 13px corner field. Buttons, panels and the composer use generous curves. Mobile panels retain rounded corners without reducing usable task width.

## Components

Appearance choices apply immediately, save to browser storage and preserve unsaved workspace-name edits. Local model templates reveal explicit model IDs without promising connected providers. Memory entries expose their original sources and saved state. Run detail shows fictional evidence as fictional. Reset offers undo while Settings remains open.

## Do's and Don'ts

Do preserve local-only product scope and clear prototype labels. Do keep one obvious next action. Do retain readable focus indicators and status text. Do not present a model label as a loaded model, a sample receipt as executed evidence, or a UI switch as runtime enforcement.
