The existing palette, landing-page composition, four main destinations, Settings tabs and local data remain the basis. No runtime dependency or hosted service was added. Optional workflows stay within existing screens.

The [original architecture illustration](assets/README.md) is bundled locally. The home preview card regains gentle hover/focus lift and a press response on fine-pointer devices. Device and in-app reduced-motion preferences keep it still.

Focused checks cover research filtering, unavailable runtime evidence, template population, scoped denial and source-path existence. Browser checks also cover setup notes and responsive image containment. These qualify the browser prototype; no Pi, model, executor or actual file effect is connected.
